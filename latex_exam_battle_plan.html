The Battle Plan

Both B1 and C2 are the same underlying exam wearing a different topic: a title block with numbered affiliations, nested lists with strange bullet symbols, one genuinely brutal spanning table, a figure that's either wrapped/rotated or a grouped subfigure grid, a wall of math with symbols you won't have time to look up, a theorem/proposition, and three cheap one-line items (footnote, hyperlink, citation) at the bottom. This board drills the pattern, not the specific paper — generic, reusable skeletons plus a symbol reference dense enough to keep open in a second window while you type.

time-budgeted by mark value copy-paste skeletons thebibliography, no BibTeX rare symbol arsenal offline materials = allowed
00

The Battle Plan

Both papers score out of 50 for a 50-minute slot — that's not a coincidence, treat it as 1 mark ≈ 1 minute of budget. The instructions on both papers explicitly say exact line breaks and float placement are not required, and the document just has to compile and closely resemble the original. That sentence is doing a lot of work: it means "good enough and compiling" beats "perfect and unfinished," every single time.

Attack in mark-value order, not document order

Reading top to bottom and writing what you meet is the instinct — resist it. Skim the mark table first, rank items by value, and write the biggest chunks while your head is clearest. A rough shape, using B1's actual distribution as the model:

RankItemMarksSuggested pace
1Big math derivation block (Laplace/RC-style transfer function, or Kepler/GR equations)8–10⏱ 12–15 min
2The spanning multirow/multicolumn table6–10⏱ 8–10 min
3Figure (wrapped+rotated, or the full subfigure grid)4–10⏱ 6–8 min
4Document structure, title, affiliations, TOC4⏱ 4 min
5Lists, nested lists, text formatting, colors4⏱ 4 min
6Code listing (if present)5⏱ 4 min
7Theorem/Proposition + proof, cross-refs2–3⏱ 3 min
8Footnote + hyperlink + citation, combined3⏱ 2 min
9Final compile, skim, fix—⏱ 5 min buffer

Notice the cheap trio at the bottom — footnote, hyperlink, citation — is worth 1 mark each on both papers. That's three one-line commands. Don't budget more than two minutes for all three combined, and don't do them first just because they're easy; do the expensive things while you have the most time left.

Skeleton first, content second

In the first four minutes, before writing a single equation, type every section heading, every \caption/\label placeholder for every required float, and the title block — even with empty or placeholder bodies. This does two things: it locks in the "Document Structure" marks almost immediately, and it turns the rest of the exam into "fill in this blank," which is a much faster mode to work in than "figure out what comes next" every few minutes.

Why this works: a half-finished document with a correct skeleton and three empty sections still visibly "closely resembles the supplied article" — which is literally the grading standard stated on both papers. A document with one perfect section and four missing ones does not.

You are allowed to use this document. Use it.

Both cover sheets say the same thing: "You may use offline materials and online searching." A dense, pre-organized symbol and skeleton reference — this one — is exactly what that sentence is inviting you to bring. The move is: keep §06 (the symbol arsenal) open in a second window the entire time, and never spend more than 10 seconds hunting for a command before checking there instead.

The One True Preamble

One block, pasted blind at t = 0, before you've even read the whole paper. It covers everything either exam pattern has ever asked for. Unused packages cost nothing.

preamble.tex — paste this first, every time 
\documentclass[a4paper,11pt]{article}
\usepackage[margin=1in]{geometry}
\usepackage{amsmath, amssymb, amsthm}
\usepackage{graphicx}
\usepackage{subcaption}
\usepackage{booktabs}
\usepackage{multirow}
\usepackage{float}
\usepackage[table]{xcolor}
\usepackage{enumitem}
\usepackage{wrapfig}
\usepackage{listings}
\usepackage{hyperref}   % load last

\newtheorem{theorem}{Theorem}[section]
\newtheorem{proposition}{Proposition}[section]
\newtheorem{lemma}[theorem]{Lemma}

\hypersetup{colorlinks=true, linkcolor=blue, citecolor=blue, urlcolor=magenta}

\lstset{basicstyle=\ttfamily\small, breaklines=true,
        frame=single, showstringspaces=false}

\begin{document}

Natbib is deliberately left out — §09 makes the case that thebibliography is faster and safer under a 50-minute clock, and both sample papers use plain numeric [1] style anyway, which needs nothing beyond what's already here. The two theorem-like environments are pre-declared with [section] numbering (so "Proposition 3.1" comes out correct automatically) — delete whichever one you don't end up needing, it costs nothing to leave both.

02

Title Blocks, Multi-Author

Both papers use superscript numbers linking each author to a numbered affiliation footnote. This is \thanks, not a plain \author string — worth having memorized rather than reconstructed live.

generic skeleton 
\title{Article Title Here}
\author{
  Author One\textsuperscript{1} \and
  Author Two\textsuperscript{2} \and
  Author Three\textsuperscript{3}
}
\date{}

% then, right before \maketitle, or via
% footnotetext tied to \maketitle:
\author{
  Author One\thanks{Affiliation One, City, Country} \and
  Author Two\thanks{Affiliation Two, City, Country}
}
what to know
\and separates multiple authors within one \author{} block — required, not optional, if you want them laid out side by side rather than concatenated into one run-on string.

\thanks{...} is the fastest path to "superscript number next to the name, footnote with the affiliation at the bottom of page 1" — it's built for exactly this pattern and needs no extra package.

If a grader is picky about matching the numbering style exactly, \textsuperscript{1} paired with a manual \footnotetext{} gives you full manual control — slower to type, use only if \thanks visibly doesn't match.
Speed call: don't chase pixel-perfect affiliation formatting. One mark of the four in "Document Structure" is the title block; getting a superscript-linked author/affiliation on the page at all, even slightly differently styled, captures it. Move on.
03

Symbol Bullets, Fast

Both papers deliberately avoid plain • and 1. bullets in favor of math symbols as list markers — this is the single most time-costly trap if you don't already know the command names cold.

The pattern, once, generalized

\begin{itemize}[label=$\oplus$]
    \item first point
\end{itemize}

\begin{itemize}[label=$\triangleright$]
    \item first point
\end{itemize}

Every symbol bullet follows this exact shape: [label=$\command$], dollar signs included, because the symbol only exists in math mode. Swap the command, nothing else changes. That means memorizing the command names below is 90% of the battle — the wrapper syntax is one line you'll type from muscle memory by your third list.

GlyphCommandSeen in
⊕\oplusB1 — "how Laplace analysis is used" list
▷\trianglerightB1 — sub-bullets under "control systems"
†\daggerC2 — inner/outer planet sub-bullets
⋄\diamondC2 — "faster/slower near the Sun" bullets
‡\ddaggernot seen yet, but same family as †
⊗\otimesnot seen yet, but same family as ⊕
⊙\odotnot seen yet — also the standard symbol for "Sun" as in $M_\odot$ (solar mass), which C2 uses inline: $M_\odot$
▶\blacktrianglerighta filled alternative to ▷
◦\circa common alternative to the default bullet
Roman-numeral parenthesized top-level labels — C2's "(I) Inner planets / (II) Outer planets" — is enumerate, not itemize: \begin{enumerate}[label=(\Roman*)]. Same braces-gotcha as before applies the moment the label text needs its own command inside it.
04

The Spanning Table Skeleton

Both papers' hardest single item is structurally the same table: a merged category column on the left, a header that splits into two sub-columns in the middle, several body rows sharing one merged category label, and — in C2 — color on top. Learn this one skeleton and both tables become a find-and-replace exercise.

The generic skeleton — memorize this shape

generic, reusable — swap the placeholder text only 
\begin{table}[H]
\centering
\rowcolors{3}{gray!8}{white}
\begin{tabular}{|c|c|c|c|}
\hline
\multirow{2}{*}{\textbf{Category}} &
  \multicolumn{2}{c|}{\textbf{Sub-Header}} &
  \multirow{2}{*}{\textbf{Note}} \\
\cline{2-3}

Five techniques, all stacked in one table, exactly as both exams do it:

LineTechnique
\multirow{2}{*}{Category} in row 1Top-left header cell spans down through the two-row header, so it isn't repeated.
\multicolumn{2}{c|}{Sub-Header}One header label spans two columns that split into separate sub-headers directly below it.
\cline{2-3}Rules off just the two sub-header columns, leaving the merged Category/Note cells uninterrupted — exactly as covered before.
\multirow{3}{*}{Group One} in the bodyOne category label spans several data rows — remember every row it spans still needs a blank leading cell.
\multicolumn{2}{\vert l\vert}{Special Row Label}A closing row where two normally-separate columns merge into one wide label — this is the "Unit-step function" row pattern from B1, and the row-color pattern from C2's table.
Speed call for the color requirement: \rowcolors{3}{gray!8}{white} called once before the tabular auto-stripes every row from row 3 onward — one line gets you "colored table" credit without hand-coloring individual cells. Only reach for per-cell \cellcolor{} if the original clearly uses color to mean something specific (status, category) rather than just alternating stripes.

Don't hand-count columns under pressure

The #1 time-sink in a table like this is a miscounted & throwing Extra alignment tab or Misplaced alignment tab character &. Build each row by literally counting the header columns first (4, in the skeleton above), writing that many &-separated slots for every row including merged ones, and only then filling in the \multirow/\multicolumn wrapping — never the reverse.

05

Wrapped, Rotated & Grouped Figures

B1 wants a wrapped-and-possibly-rotated single figure; C2 wants nine subfigures arranged in three visually labelled groups sharing one caption. Different shapes, same underlying subfigure/wrapfigure toolkit from your last two boards.

Wrapped + rotated, combined

\begin{wrapfigure}{r}{0.35\linewidth}
    \centering
    \includegraphics[width=\linewidth, angle=15]{diagram.png}
    \caption{Caption text.}
    \label{fig:wrapped}
\end{wrapfigure}

Just the two techniques from your earlier boards stacked in one \includegraphics call — angle= inside the same options list as width=. Nothing new syntactically; the only real risk is spending time guessing the right angle value. Any visible rotation captures the mark — don't hunt for the exact original degree.

Grouped subfigures sharing one caption — the fast skeleton

C2's real challenge: nine subfigures, lettered (a) through (i) continuously, but visually clustered under three bold un-numbered group titles ("Star," then a row of four, then a row of four). The key fact that makes this fast: subfigure lettering only tracks the order \begin{subfigure} blocks appear in — plain text or spacing between them never resets or interrupts the sequence.

generic skeleton — three groups, one figure, one caption 
\begin{figure}[H]
\centering

\textbf{\large Group One}\par\vspace{4pt}
\begin{subfigure}{0.3\linewidth}
    \centering\includegraphics[width=\linewidth]{a}
    \caption{Item A}
\end{subfigure}

\vspace{10pt}
\textbf{\large Group Two}\par\vspace{4pt}
\begin{subfigure}{0.22\linewidth}
    \centering\includegraphics[width=\linewidth]{b}
    \caption{Item B}
\end{subfigure}\hfill

    \centering\includegraphics[width=\linewidth]{c}
    \caption{Item C}
\end{subfigure}\hfill

    \centering\includegraphics[width=\linewidth]{d}

The rule you must not break, restated: a blank line between two subfigures meant for the same row forces an unwanted break. But a blank line (or \vspace) between the last subfigure of one group and the group title of the next is exactly what you want — that's a deliberate row/section break, not an accident. The difference is intent, not the presence of a blank line itself.

\textbf{\large Group Name}\par\vspace{4pt} is doing double duty: \par ends that line as its own paragraph without leaving a true blank-line gap before the subfigure row starts, and \vspace{4pt} nudges a small visual gap in without triggering the same-row-break problem.

Multi-level indices & tensor notation

C2's general-relativity block (Einstein field equations, the geodesic equation) is really just ordinary sub/superscripts pushed further than usual — the syntax doesn't change, only the density of it does.

source 
G_{\mu\nu} + \Lambda g_{\mu\nu} =
  \frac{8\pi G}{c^4} T_{\mu\nu}

\frac{d^2 x^\mu}{d\tau^2} +
  \Gamma^{\mu}_{\alpha\beta}
  \frac{dx^\alpha}{d\tau}
  \frac{dx^\beta}{d\tau} = 0
how to read it
G_{\mu\nu} — a two-index (rank-2 tensor) subscript; both Greek letters go inside one pair of braces, comma-free.

\Gamma^{\mu}_{\alpha\beta} — one superscript index and two subscript indices on the same symbol (Christoffel symbol) — type the superscript group and the subscript group as two separate ^{...}/_{...} blocks immediately after the base symbol, order doesn't matter to LaTeX.

x^\mu next to d\tau^2 — a superscript index on a variable is not multiplication or an exponent conceptually, just visually identical syntax; LaTeX doesn't need to know the difference, you do.

Greek letters for indices: \mu \nu \alpha \beta \gamma \sigma \tau are the standard set — all already in your first board's Greek table.

Fast Multi-Step Derivations

B1's transfer-function derivation uses implication arrows (⇒) as the connector between lines instead of an equals sign — a small but easy-to-fumble variant of the align pattern from your earlier boards.

generic skeleton 
\begin{align}
    & \text{starting expression} \\
    \implies\ & \text{step two} \\
    \implies\ & \text{step three, final form}
\end{align}
what to notice
The & still marks the alignment column, exactly as before — it just now sits right after \implies instead of right before an =, so every line's implication arrow stacks in one column instead of every line's equals sign.

A thin space \ (backslash-space) directly after \implies is a small polish detail, not a requirement — skip it if you're racing the clock, it costs nothing structurally to leave out.
Speed call: for a right-hand-side-only continuation line (like B1's three-line block where every line ends in = V_\text{in}(s)), you don't need to retype the left-hand side each time — leave the space before & empty on continuation lines, exactly as your second board's quadratic-formula example already showed.
08

Proposition/Proof, Numbered Per Section

C2 labels its result "Proposition 3.1" — section number, dot, running counter — which is specifically the [section] reset pattern flagged as easy to confuse with the counter-sharing pattern in your earlier board. This is the one to have pre-declared, not derived live.

preamble (already in §01's block) 
\newtheorem{proposition}{Proposition}[section]
usage 
\begin{proposition}[Short Title]
    \label{prop:example}
    Statement of the proposition.
\end{proposition}

\begin{proof}
    Proof text here.
\end{proof}

The [section] at the very end of the \newtheorem line — not [theorem] right after the environment name — is what produces "3.1" instead of a plain running "1, 2, 3." Get this backwards and the numbering compiles fine but doesn't match the original at all, which is an easy silent point-loss under time pressure.

09

Citations Without the BibTeX Tax

Both papers use plain numeric [1], [2], [3] references — worth exactly 1 mark. Under a 50-minute clock, running the full pdflatex → bibtex → pdflatex → pdflatex cycle from your earlier board, or getting a filename wrong between your .tex and a separate .bib, is a real risk for one mark. There's a faster, equally correct alternative.

thebibliography — one pdflatex pass, no .bib file 
As discussed in \cite{ref1}, ...

\begin{thebibliography}{9}
\bibitem{ref1} A. Author, \textit{Title of the Book},
  Xth ed. Publisher, Year.
\bibitem{ref2} B. Author, ``Title of the Paper,''
  \textit{Journal Name}, Year.
\end{thebibliography}
why this is the right call here
Compiles correctly in a single pdflatex run — no separate .bib file, no bibtex step, no risk of a filename mismatch under pressure.

\cite{ref1} still works exactly as before and, with hyperref loaded, is still automatically clickable.

Numbers are assigned in the order the \bibitems are listed — so list them in the same order the original numbers them, and the output matches without any extra thought.

The {9} is just a width hint for the label column — it doesn't need to be exact, just roughly the right order of magnitude (use {99} if you have 10 or more references).
Speed call: this is the single highest-leverage strategic swap in this whole board relative to how little it costs to learn. It converts a 1-mark item with real compile risk under time pressure into a 1-mark item with almost none.

Footnotes & Hyperlinks — Cheap Points

Two more 1-mark items. Both are a single command. Do them last, do them fast, don't overthink either.

both, back to back 
...as discussed by MathWorld\footnote{Additional
context or a source note goes here.}.

See the \href{https://example.com}{MathWorld}
page for details, or the raw address:
\url{https://example.com}.
rendered
...as discussed by MathWorld1.

See the MathWorld page for details, or the raw address: https://example.com.

Any real-looking URL satisfies the hyperlink mark — it doesn't need to resolve to a live page during grading of a reproduction exercise focused on markup, though matching the original's actual link text is safest if you remember it.

Code Listings, Fast

B1 imports an external .py file rather than retyping it. If the file is provided (as it was here — rc_response.py), always import it rather than retype it: faster, and zero risk of a transcription typo breaking the "successful compilation" requirement.

\lstinputlisting[language=Python,
  caption={Computing samples of the RC step response.},
  label={lst:rc-response}]{rc_response.py}

Path is relative to your .tex file, exactly like an image path. The \lstset{} defaults already sitting in §01's preamble (monospace, framed, line-wrapping) are enough on their own — don't spend exam time hand-tuning colors for a 5-mark item when the content and structure are what's actually being graded.
