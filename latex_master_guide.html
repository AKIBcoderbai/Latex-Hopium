Preamble Starter Kit

Every technical document begins here. If an advanced command like \multirow or \sout fails to compile, check this checklist first to ensure you haven't forgotten its package.

universal_preamble.tex
\documentclass[10pt,a4paper]{article}

% --- MATH & ENCODING ---
\usepackage[utf8]{inputenc}
\usepackage{amsmath, amssymb, amsfonts} % cases, align*, \mathcal, \mathbb

% --- GRAPHICS & FLOATS ---
\usepackage{graphicx}                   % \includegraphics
\usepackage{subcaption}                 % subfigure environments
\usepackage{float}                      % [H] absolute float placement

% --- TABLES & COLORS ---
\usepackage{booktabs}                   % \toprule, \midrule, \bottomrule
\usepackage{multirow}                   % \multirow cell merging
\usepackage[table]{xcolor}              % text colors + \rowcolor, \cellcolor

% --- LISTS & TEXT STYLING ---
\usepackage{enumitem}                   % custom enumerate/itemize labels
\usepackage[normalem]{ulem}             % \sout strikethrough (normalem preserves \emph)

% --- REFERENCES & CITATIONS ---
\usepackage[numbers]{natbib}            % [numbers] for [1], [authoryear] for (Author, 2026)
\usepackage{hyperref}                   % LOAD LAST: clickable links & colored references
\hypersetup{colorlinks=true, linkcolor=blue, urlcolor=magenta, citecolor=green}
PackageWhat It Unlocks For You
amsmath, amsfonts\begin{align*}, \begin{cases}, \text{} inside math, calligraphic \mathcal{N}, and matrices.
multirowAllows table cells to merge vertically across multiple rows using \multirow{rows}{width}{text}.
booktabsProfessional table horizontal rules (\toprule, \midrule, \bottomrule) with proper padding.
xcolor [table]Text colors (\textcolor), highlights (\colorbox), and table cell shading (\rowcolor, \cellcolor).
enumitemCustom list labels like [label=(\alph*)], [label=\Roman*.], or geometric symbols.
subcaptionCreates side-by-side or asymmetric sub-images with distinct (a), (b), (c) tags inside one figure.
ulem [normalem]Enables \sout{strikethrough}. Always use [normalem] so it doesn't accidentally change italics into underlines!
natbibAllows seamless toggling between numeric citations [1] and author-year citations (Author, 2026).
hyperrefTurns references, citations, and URLs into clickable links. Always import this package absolute last!

Pro-Tip on \emph vs \textit: \emph{} is smart! If you use it inside a sentence that is already italicized (like a theorem), it automatically flips the text back to upright roman font so it still stands out. \textit{} will stay italic no matter what.

The Ghost Cell Rule for \multirow: Look at the second row of headers in the source code: & \textbf{4?} & \textbf{100?} ... Notice the empty space before the first ampersand! Because \multirow{2}{*}{Year} drops down from the row above to occupy Column 1, you must leave Column 1 blank on the row below so text doesn't collide.

Math Engine & Piecewise Functions

From Online A2 & C2: Multi-line algebra alignments, calligraphic probability notations, and the tricky cases environment.

The align* Environment & Operator Limits

LaTeX Source
We derive the quadratic root formula:
\begin{align*}
    ax^2 + bx + c &= 0 \\
    \left(x + \frac{b}{2a}\right)^2 &= \frac{b^2 - 4ac}{4a^2} \\
    x &= \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}
\end{align*}

Variance summation with explicit limits:
\begin{equation}
    T = \sum\limits_{i=1}^{n} (x_i - \mu)^2
\end{equation}

Optimal vertex selection: $\max\limits_{v \in V} f(v)$
Rendered PDF Output

Why use \limits? In an inline sentence, LaTeX naturally slants subscripts to the side (max_v) to save space. Adding \limits immediately after operators like \max\limits, \min\limits, or \sum\limits forces the variable to sit directly underneath!

Calligraphic Symbols & Piecewise Functions (\cases)

Online A2 & C2 Math Code
% Calligraphic normal distribution:
\begin{equation}
    \mathcal{N}(x_i, \mu, \sigma) = 
    \frac{1}{\sqrt{2\pi}\sigma} e^{-\frac{(x_i-\mu)^2}{2\sigma^2}}
\end{equation}

% Piecewise conditional states:
\begin{equation}
    f(x_i) = \begin{cases}
        \frac{x_i^2}{\sigma^2}, & \text{if } x_i \ge 0 \\
        \frac{|x_i|}{\sigma},  & \text{if } x_i < 0
    \end{cases}
\end{equation}

The \text{} Command Trap: Inside \begin{cases}, you must wrap words like "if" in \text{if }! If you type normal text without \text{}, LaTeX interprets every letter as an algebraic variable, squishing them together in italics without spaces.

Citations & BibTeX Pipeline (PDF to Reference)

How to extract citation data from an exam PDF, build your database, and switch between numeric [1] and author-year (Author, 2026) styles.

Step 1 & 2: Creating the references.bib File

When an online exam gives you raw paper details (Author, Title, Journal, Year), create a plain text file named references.bib and structure it using standard BibTeX syntax:

references.bib
@article{meeus1991astronomical,
    author  = {Meeus, Jean},
    title   = {Astronomical Algorithms for Planetary Calculation},
    journal = {Willmann-Bell Review},
    year    = {1991},
    volume  = {24},
    pages   = {15--30}
}

@book{knuth1994concrete,
    author    = {Graham, Ronald L. and Knuth, Donald E. and Patashnik, Oren},
    title     = {Concrete Mathematics: A Foundation for Computer Science},
    publisher = {Addison-Wesley Longman},
    year      = {1994},
    edition   = {2nd}
}

Step 3: Toggling Numeric vs Author-Year in Main Document

main_document.tex
% --- PREAMBLE ---
% Use [numbers] for [1], or [authoryear] for (Author, 1991):
\usepackage[authoryear]{natbib}

\begin{document}
% Parenthetical citation \citep gives full brackets:
Leap years correct accumulated orbital drift \citep{meeus1991astronomical}.

% Textual citation \citet mixes name into sentence:
According to the foundational proof by \citet{knuth1994concrete}, 
Stirling numbers scale exponentially.

% --- PRINT REFERENCES AT END ---
\bibliographystyle{plainnat}
\bibliography{references}
\end{document}
Rendered PDF Output (Author-Year Mode)
Leap years correct accumulated orbital drift (Meeus, 1991).

According to the foundational proof by Graham et al. (1994), Stirling numbers scale exponentially.

References
Graham, R. L., Knuth, D. E., and Patashnik, O. (1994). Concrete Mathematics: A Foundation for Computer Science. Addison-Wesley Longman, 2nd edition.

Meeus, J. (1991). Astronomical algorithms for planetary calculation. Willmann-Bell Review, 24:15–30.
The Mandatory 4-Pass Compile Protocol: When compiling locally (TeXstudio/VS Code), seeing [?] question marks means your database hasn't linked! You must run: pdfLaTeX → BibTeX → pdfLaTeX → pdfLaTeX. This 4-step chain is required to read the keys, build the bibliography, and link the inline tags.
