Package Starter Kit

Paste this preamble once. Almost everything below depends on one of these lines — if a command "doesn't exist" during compilation, this table is the first place to check.

preamble.tex 
\documentclass{article}

\usepackage[utf8]{inputenc}
\usepackage{amsmath, amssymb}     % cases, align, matrices
\usepackage{graphicx}             % \includegraphics
\usepackage{subcaption}           % subfigures
\usepackage{booktabs}             % \toprule \midrule \bottomrule
\usepackage{multirow}             % \multirow
\usepackage[table]{xcolor}        % colors + \rowcolor, \cellcolor
\usepackage[normalem]{ulem}       % \sout strikethrough (keeps \emph italic)
\usepackage{enumitem}             % custom list labels/spacing
\usepackage{natbib}               % \citet / \citep author-year
\usepackage{hyperref}             % load LAST: \url, \href, colored refs
PackageUnlocks
multirowMerge table cells vertically (a label spanning two rows).
booktabsClean \toprule/\midrule/\bottomrule rules instead of full grids.
xcolor (with table option)Text colors, highlight boxes, and colored table rows/cells.
enumitemChange enumerate/itemize labels to (a), i., A), custom symbols, and control spacing.
subcaptionMultiple labelled sub-images (a), (b), (c) inside one figure.
ulem\sout{} strikethrough text.
hyperrefClickable \url, \href, colored cross-references. Always load last.
natbibSwitch citations between numeric [1] and author-year (Author, Year).
01

Text Formatting

The C2 paper explicitly stacked bold, italic, emphasis, underline, strikethrough, sizes and color in one paragraph — treat it as a checklist.

Weight, slant, emphasis, underline

source 
This sentence has \textbf{bold},
\textit{italic}, \emph{emphasized},
and \underline{underlined} text.
rendered
This sentence has bold, italic, emphasized, and underlined text.

\emph{} is context-aware: inside normal text it italicizes, but inside already-italic text (like a theorem statement) it flips back to upright. \textit{} never flips — it's always italic.

Strikethrough (needs a package)

Base LaTeX has no strikethrough command. Load ulem with the [normalem] option — without that option, ulem hijacks \emph to mean "underline" instead of italic.

source 
% preamble: \usepackage[normalem]{ulem}
The old deadline was \sout{March 3}.
rendered
The old deadline was March 3.

Color: text, highlight boxes, custom colors

source 
\definecolor{buetblue}{HTML}{1B4F72}

\textcolor{red}{Warning text.}
\textcolor{buetblue}{Custom color text.}
\colorbox{yellow}{Highlighted text.}
\fcolorbox{black}{yellow}{Framed highlight.}
rendered
Warning text.
Custom color text.
Highlighted text.
Framed highlight.

This same \textcolor/\colorbox machinery is what colors table cells later — one package, two use-cases.

Font size & family

source 
{\tiny tiny} {\small small} {\normalsize normal}
{\large large} {\Large Large} {\LARGE LARGE}
{\huge huge} {\Huge Huge}

\textrm{serif} \quad \textsf{sans-serif} \quad \texttt{monospace}
rendered
tiny small normal large Large LARGE huge Huge
serif   sans-serif   monospace

The size commands are ranked in strictly this order (both directions): tiny → scriptsize → footnotesize → small → normalsize → large → Large → LARGE → huge → Huge. Scope them with { } so the size doesn't leak into the rest of the document.

Lists & Labelling

The Image Synthesis paper mixed itemize and enumerate, used roman numerals, sub-bullets, and a bold inline "mini-header" item — this is the full toolkit behind that.

Enumerate labelling variations (enumitem)

source 
\begin{enumerate}[label=(\alph*)]
  \item divisible by 4
  \item divisible by 400
\end{enumerate}

\begin{enumerate}[label=\Roman*.]
  \item Primary Rays
  \item Secondary Rays
\end{enumerate}

\begin{enumerate}[label=\arabic*), start=3]
  \item continues from three
\end{enumerate}
rendered
(a) divisible by 4
(b) divisible by 400
I. Primary Rays
II. Secondary Rays
3) continues from three

Common label tokens: \alph* = a,b,c · \Alph* = A,B,C · \roman* = i,ii,iii · \Roman* = I,II,III · \arabic* = 1,2,3.

Nested / mixed lists + a bold "mini-header" item

source 
\begin{itemize}
  \item Scene Definition
  \item Camera Configuration
    \begin{itemize}
      \item Light Placement
    \end{itemize}
  \item \textbf{Important} Shading Model
    \begin{itemize}
      \item Diffuse Shading
      \item Specular Highlights
    \end{itemize}
\end{itemize}
rendered
  • Scene Definition
  • Camera Configuration
    • Light Placement
  • Important Shading Model
    • Diffuse Shading
    • Specular Highlights

There's no special "mini-header" command — it's just a normal \item whose text starts with \textbf{}, followed by a nested itemize. This exact pattern is what the Image Synthesis paper's rendering pipeline list was testing.

Description lists & tight spacing

  \item[Note] Lists can be customized.
\end{description}

\begin{itemize}[noitemsep, topsep=2pt]
  \item compresses the gaps
  \item between items
\end{itemize}

03

Sections & Document Structure

Every past paper used a title block plus a numbered section hierarchy, and at least one unnumbered heading ("Disclaimer", "Conclusion").

Title block

\title{The History Behind Leap Year}
\author{Your Name (Your Student ID)}
\date{\today}

\begin{document}
\maketitle

Section hierarchy

\section{History}
\subsection{Julian Calendar}
\subsubsection{Detail}
\paragraph{Aside.} inline run-in text

Unnumbered headings that still need a Table of Contents entry

A plain \section*{Disclaimer} has no number and is invisible to \tableofcontents — add it manually if you want it listed:

\section*{Disclaimer}
\addcontentsline{toc}{section}{Disclaimer}

\tableofcontents itself needs two compiles: the first pass writes a .toc file, the second pass reads it back in.

Tables — multirow & multicolumn

This is exactly what the Leap Year paper's "Divisible By" spanning header, and the Document Structure paper's merged "Module B" row, were built from.

\multicolumn — one header spanning several columns

source 
\begin{tabular}{|c|c|c|c|c|}
\hline
\multirow{2}{*}{Year} & \multicolumn{3}{c|}{Divisible By} & \multirow{2}{*}{Leap Year?} \\
\cline{2-4}
 & 4? & 100? & 400? & \\
\hline
1900 & Yes & Yes & No  & No  \\
2000 & Yes & Yes & Yes & Yes \\
2024 & Yes & No  & No  & Yes \\
\hline
\end{tabular}

\multicolumn{3}{c|}{...} reads as: span 3 columns, center-align, put a | vertical rule after. \cline{2-4} draws a horizontal rule under only columns 2–4, leaving the merged "Year"/"Leap Year?" cells uninterrupted. \multirow{2}{*}{Year} (from the multirow package) merges that cell down through 2 rows.

Booktabs style + colored rows/cells

source 
\begin{tabular}{lcc}
\toprule
Method & Accuracy & Time \\
\midrule
\rowcolor{gray!15} Rasterization & Medium & $O(n)$ \\
Ray Tracing & High & $O(n^2)$ \\
Hybrid & \cellcolor{yellow!40}High & $O(n^2)$ \\
\bottomrule
\end{tabular}
rendered

RasterizationMediumO(n)

booktabs intentionally has no vertical rules — that's the professional convention, not a mistake. \rowcolor{} tints a whole row; \cellcolor{} tints one cell; both need \usepackage[table]{xcolor}.

Positioning, captions, and column types

\begin{table}[htbp]
  \centering
  \begin{tabular}{l p{4cm} r}
    ...
  \end{tabular}
  \caption{Comparison of Image Synthesis Techniques}
  \label{tab:comparison}
\end{table}

[htbp] = try here, else top, else bottom, else its own page (add ! to force LaTeX to relax its placement rules). Column types: l/c/r = fixed-width left/center/right, p{width} = fixed-width paragraph (wraps text, top-aligned), m{width}/b{width} (from array package) = same but middle/bottom aligned. Leaving a cell empty (just &) — like the missing method name in your Image Synthesis table — is perfectly valid syntax.

Figures & Subfigures

Two layouts appeared across your papers: an even side-by-side row (Leap Year, Image Synthesis) and an asymmetric "one big + two small" layout (Document Structure C2).

Even row of subfigures

Two widths that sum to less than 1 (0.45 + 0.45 = 0.9) leave the leftover 0.1 as the gap. \hfill pushes the two boxes apart to use that space evenly; swap it for a fixed \hspace{1cm} if you want an exact gap instead of a stretchy one.

A blank line (or explicit \vspace{}) between subfigure blocks starts a new visual "row" — LaTeX just wraps subfigures like words wrap in a paragraph, once a row's total width exceeds \textwidth.

\includegraphics sizing options

\includegraphics[width=0.6\textwidth]{fig}   % relative to text width
\includegraphics[height=4cm]{fig}            % fixed height
\includegraphics[scale=0.5]{fig}             % scale factor
\includegraphics[width=5cm, angle=90]{fig}   % rotate

Math & Piecewise Functions

Both the Image Synthesis and Document Structure papers used cases for piecewise functions — this trips people up more than any other math environment.

Piecewise functions with cases

source 
|y| =
\begin{cases}
  y  & \text{if } y \geq 0 \\
  -y & \text{if } y < 0
\end{cases}
rendered
|y| = {
yif y ≥ 0
−yif y < 0

Needs amsmath. Each line is value & condition, separated by \\. Use \text{...} (not plain words) for the "if" labels, or LaTeX will italicize and cramp the letters as if they were variables.

Multi-line derivations with align

source 
\begin{align}
  f(x) &= x^2 + 2x + 1 \\
       &= (x+1)^2
\end{align}
rendered
f(x) = x² + 2x + 1     (1)
    = (x + 1)²     (2)

Every line is numbered by default. Use \notag at the end of a line to suppress just that line's number, or align* to suppress all numbering.

Matrices, fractions, sums

source 
k = \dfrac{ab}{cd}

M = \begin{pmatrix} a & b \\ c & d \end{pmatrix}

T = \sum_{i=1}^{n} (x_i - \mu)^2

N(x_i,\mu,\sigma) = \dfrac{1}{\sqrt{2\pi}\sigma}
   e^{-\frac{(x_i-\mu)^2}{2\sigma^2}}
rendered
k = ab⁄cd
M = ( a b ; c d ) — parentheses matrix
T = Σi=1n (xᵢ − μ)²
N(xᵢ,μ,σ) = 1⁄(√(2π)σ) · e^(−(xᵢ−μ)²/2σ²)

Matrix variants: pmatrix ( ), bmatrix [ ], vmatrix | | (determinant), Bmatrix { }. \frac shrinks inside inline text; \dfrac forces full display size even inline.

Inline vs. display, numbering & referencing

Inline: the term $e^{x^2}$ appears mid-sentence.

\begin{equation}
  L = I_{ij} \cdot \cos(\theta) + R^2
  \label{eq:lighting}
\end{equation}

As shown in Equation~\eqref{eq:lighting}, ...

\eqref{} (from amsmath) auto-wraps the number in parentheses, e.g. "(1)" — plain \ref{} on an equation label gives just "1".

Cross-references & Hyperlinks

Labels tie a figure/table/equation/section to a number; hyperref makes every one of those numbers (plus every citation) a clickable link.

Label / ref family

CommandProduces
\label{fig:pioneers}Attaches a name to the nearest numbered thing (figure/table/section/equation).
\ref{fig:pioneers}Just the number, e.g. "1".
\pageref{fig:pioneers}The page number that label sits on.
\eqref{eq:lighting}The number wrapped in parentheses: "(1)".

Place \label after \caption in figures/tables (captions assign the number) — placed before, it will reference the wrong number.

hyperref setup + \url vs \href

source 
% load LAST in the preamble
\usepackage{hyperref}
\hypersetup{
  colorlinks=true,
  linkcolor=blue,
  citecolor=teal,
  urlcolor=magenta
}

See \url{https://en.wikipedia.org/wiki/...}
or \href{https://en.wikipedia.org/wiki/...}{this page}.
rendered
See https://en.wikipedia.org/wiki/...
or this page.

\url{} prints the raw address verbatim (good inside a footnote or reference list). \href{link}{text} hides the address behind readable words. Load hyperref as the very last \usepackage — most conflicts trace back to something being loaded after it.

Citations & Building a .bib File from a PDF

Every paper you sent ended in a numbered reference like [1] Jean Meeus. Astronomical Algorithms... — that number is generated, never typed by hand. Here's the full pipeline: PDF → .bib entry → citation style.

Step 1 — pull the fields out of the source PDF

When you only have a PDF (not a DOI), extract these by hand from the cover/title page and copyright page:

FieldWhere to find it
Author(s)Title page — keep "Last, First" order, join multiple authors with and.
TitleTitle page, exact capitalization.
YearCopyright page ("©") or title page.
Publisher / JournalCopyright page (books) or the journal header/footer on each page (articles).
Volume, Number, PagesJournal articles only — usually in the running header/footer.
DOIFirst page or copyright page, format 10.xxxx/xxxxx.
Shortcut: if you have the title, search it on Google Scholar → click the quotation-mark "Cite" icon → "BibTeX" — it hands you a ready-made entry. If you have a DOI instead, paste it into doi2bib.org for the same result. Manual extraction (below) is your fallback when neither exists.

Step 2 — write the entry into references.bib

references.bib 
@book{meeus1991,
  author    = {Meeus, Jean},
  title     = {Astronomical Algorithms},
  publisher = {Willmann-Bell Inc.},
  year      = {1991}
}

@book{graham1994concrete,
  author    = {Graham, Ronald L. and Knuth, Donald E.
               and Patashnik, Oren},
  title     = {Concrete Mathematics: A Foundation
               for Computer Science},
  edition   = {2nd},
  publisher = {Addison-Wesley Longman},
  address   = {USA},
  year      = {1994}
}
entry types cheat-sheet
@article — author, title, journal, year, volume, number, pages

@inproceedings — author, title, booktitle, year, pages

@book — author/editor, title, publisher, year

@incollection — chapter inside an edited book

@misc — author, title, year, note/howpublished, url — for websites, GitHub repos, datasets

The word right after the opening brace (meeus1991) is the citation key — anything unique, no spaces. That's the string you'll type inside \cite{}.

Step 3a — numeric style, gives [1]

source 
% preamble
\bibliographystyle{plain}   % or ieeetr, unsrt, abbrv

% in text
As discussed by Meeus \cite{meeus1991}, ...

% at the very end of the document
\bibliography{references}
rendered
As discussed by Meeus [1], ...

Step 3b — author-year style, gives (Author, Year)

source 
% preamble
\usepackage{natbib}
\bibliographystyle{plainnat}   % or apalike

% in text
\citet{meeus1991} showed that ...      % textual
Leap years correct for drift \citep{meeus1991}.  % parenthetical
rendered
Meeus (1991) showed that ...
Leap years correct for drift (Meeus, 1991).

The same .bib file drives both formats — switching [1] ↔ (Author, Year) is purely a matter of which bibliography style you pick and whether you load natbib, never a matter of rewriting the .bib file.

Compile order matters: pdflatex → bibtex → pdflatex → pdflatex (four runs). Skipping steps is the #1 reason references show up as "[?]". Tools like latexmk -pdf automate this.

Loose Ends Worth Knowing

Small things that showed up once each across your papers and are easy to forget under exam pressure.

Footnotes

have applications in computer science
\footnote{\url{https://en.wikipedia.org/...}}

Place \footnote{} immediately after the word it annotates — numbering and page placement are automatic.

Block quotations

\begin{quote}
Don't forget to practice more problems!
\end{quote}

Indents both margins slightly — used for the closing remark in the Stirling Numbers paper.

Table of Contents

\tableofcontents
\newpage

Two compiles minimum, always

Anything that depends on "what number will this be" — TOC, cross-references, and citations — is wrong on the very first compile and correct by the second (or, for citations, the fourth run through the bibtex cycle above). Seeing a "?" in place of a number almost always means: compile again.
